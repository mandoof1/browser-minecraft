browser-minecraft · Minecraft 1.8.8 in WebAssembly

boot screen: -
Click the game once to start it (the engine waits for a real user gesture before it opens its audio context), and again to grab the mouse. Keys: WASD move · space jump · shift sneak · mouse look · left click break · right click place · middle click pick block · 1-9 hotbar · wheel cycle hotbar · E inventory · T chat · F3 debug · Esc menu. Worlds are saved by the game itself into IndexedDB, so a reload resumes them.
Query params: ?build=wasm|js · ?mode=files|epw · ?server=ws://host/ · ?lang=en_US · ?nocache=1 · ?opts=enforceVSync=1
